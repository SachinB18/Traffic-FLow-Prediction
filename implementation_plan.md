# Traffic Flow Prediction — STFormer-Inspired Project Plan

## Background

You are building a **traffic flow prediction** system for an AIML course project. The research paper is **STFormer** (IEEE CyberSciTech 2024), which proposes a Spatio-Temporal Transformer architecture combining:
- A **Closeness Component** (short-range temporal patterns)
- A **Period Component** (long-range/periodic patterns)
- Multi-head self-attention for both spatial and temporal dependencies
- A **Fusion & Prediction** module using learnable parameter matrices

The dataset is **METR-LA** (207 traffic sensors in LA, 5-min intervals, ~4 months of speed data). It is the same dataset referenced in the paper.

### `04_STFormer_Scratch.ipynb` — From Scratch (Paper's Model)
Core architecture from the paper:
```
Input → Temporal Tokenizer (patch embedding + positional encoding)
      → Closeness Component: L × STR-Unit(Temporal Transformer + Spatial Transformer)
      → Period Component: L × STR-Unit
      → Fusion & Prediction (learnable parameter matrix α, β)
      → Output
```
- Hyperparams: 2 ST-Transformer blocks, 4 attention heads, 2 residual units
- Batch size: 8 (as in paper), lr: 3e-4
- This is the **main model** of the project

### `05_Library_Models.ipynb` — From Libraries
- **Random Forest Regressor** and **XGBoost** from `sklearn`/`xgboost`
- Input: flattened windows `(N, 12×207)` → output `(N, 207)`
- Much faster but no temporal structure
- Useful as baseline to show DL superiority

### `06_Transformer_Library.ipynb` — Library Transformer
- Use PyTorch's `nn.Transformer` / `nn.TransformerEncoder` directly
- Shows the difference between raw library use vs the paper's custom design

### `07_Model_Comparison.ipynb`
